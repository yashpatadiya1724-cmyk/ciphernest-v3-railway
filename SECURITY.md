# Security Policy — CipherNest v2

## Supported Versions

| Version | Supported |
|---|---|
| `v2.x` (Cloud-Native Mobile / Railway) | ✅ Yes |
| Earlier experimental versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, flaw in cryptography implementation, or credential leakage within CipherNest, please report findings responsibly:
- **Lead Maintainer:** Yash Patadiya
- **Response Window:** Within 48 hours with an initial severity triage and remediation plan.
- **Detailed Policy:** See [docs/SECURITY.md](docs/SECURITY.md) for complete cryptographic threat model, key residency policies, and disclosure guidelines.
